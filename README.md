# ThreatLens

ThreatLens is a Java-based command-line cybersecurity tool that analyzes URLs for common suspicious characteristics and generates a simple threat score.

## Features

- URL length analysis
- HTTPS security check
- Suspicious keyword detection
- Suspicious symbol detection
- Numeric pattern detection
- IP address pattern detection
- Risk score generation from 0 to 100
- LOW RISK, SUSPICIOUS and HIGH RISK classification
- Command-line execution

## Technology Used

- Java 21
- Java Scanner
- Regular Expressions
- Conditional logic and arrays
